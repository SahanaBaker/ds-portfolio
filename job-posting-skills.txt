Things that stood out to me:
Now that I think about it, it makes sense that intersection has a lot more emphasis on writing clearly and documentation. Communication is very important in Data Science because the results of analysis and the specifications for tools both require communicating with whoever is using them. Now that I think about it, it makes sense that soft skills like communication would be more relevant to a wider variety of jobs since they’re more applicable to more situations than, for example, a specific programming language.
